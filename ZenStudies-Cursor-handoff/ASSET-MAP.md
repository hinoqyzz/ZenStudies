## Regras

- Referências de interface orientam composição e hierarquia; não devem ser usadas como background.
- O logotipo não deve ser redesenhado.
- Não gerar novos ícones de marca: usar Lucide para ações e os SVGs fornecidos para identidade.
- Não criar novas imagens raster antes de existir uma necessidade real de produto.
